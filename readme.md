# Primer Proyecto con Git y GitHub

Este es un proyecto de práctica para aprender el flujo de trabajo con Git y GitHub.

## Funcionalidades implementadas

- Estructura base en HTML
- Barra de navegación (navbar)
- Footer básico

## Flujo de trabajo con ramas

- `master`: rama principal
- `feature/navbar`: implementación de la barra de navegación
- `feature/footer`: implementación del footer

Los cambios fueron integrados mediante Pull Requests.
